# Problem Statement and scope

## Problem Statement
Manual student score calculation is time-consuming and prone to human error.

## Project Scope
The Smart Student Analysis System is a python console application that automates total calculation, percentage evaluation, grade assignment ,and result determination for 5 core subject.

## Target Users
* Teachers and Academic Evaluators.
* Students checking their performance.

## Core Features
* Automated total and percentage computation.
* Dynamic letter grading  (A+ to F).
* Result determination (PASS/FAIL).
